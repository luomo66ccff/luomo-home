# 移动端加载性能记录 · 2026-10-09

首次加载时，主线程同时布局八个板块，开场遮罩背后的场景也在运行。基线追踪中，首次整页布局约 2.31 秒、涉及 2442 个布局对象。Live2D 通讯面板初始关闭，没有下载模型或 PixiJS，因此此次先处理布局与场景动效。

## 实现

- 宽度不超过 767px 时，首屏外板块使用 `content-visibility:auto`，保留服务端内容、原生锚点及按实测高度设置的占位。
- 共享一个 IntersectionObserver 控制屏外场景；开场遮罩和后台状态同时暂停 CSS、SVG SMIL 与 Canvas。当前主题下透明的反射/闪光动画也暂停。
- 手机星空以 30fps 更新，保留星数和 DPR，并通过时间增量保持流星速度。尺寸没有变化时不重建画布。
- 乘务员通讯关闭时停止板块测量；打开时补算，滚动通过 requestAnimationFrame 合并。
- 新快速存档保存板块内偏移，读档时暂时展开布局后定位；旧绝对位置存档继续兼容。

## 对比条件

两个版本均使用本机生产构建：基线是 main `901e9acb8fb6bf5aa63f0dfeeee4633e4c62f2ba` 的应用代码，优化版包含本次改动。浏览器为 Windows 上的无头 Microsoft Edge 154；视口 390×844、DPR 2、触摸/移动模式、深色主题，开启正常动效。CDP 设置 CPU 6 倍降速、网络延迟 40ms、下载 1,500,000 B/s、上传 750,000 B/s、禁用缓存。

每个版本使用三个新的浏览器上下文采样，各观察加载后 8 秒；第一轮记录追踪，另外两轮不追踪。下表为三轮中位数，属于浏览器实验室测试，未采集实体手机或线上用户数据。

| 指标 | 基线 | 优化版 | 变化 |
| --- | ---: | ---: | ---: |
| 加载前 4 秒的主线程阻塞 | 3428ms | 1949ms | 减少 43.1% |
| 加载前 4 秒最长任务 | 2516ms | 1410ms | 减少 44.0% |
| 第 4–8 秒 rAF 帧间隔 P95 | 74.9ms | 20.9ms | 减少 72.1% |
| 最后一次 LCP 候选时间 | 3208ms | 1924ms | 提前 40.0% |
| 初始 8 秒布局偏移总和 | 0.00140 | 0.00926 | 仍较低，略有增加 |

“主线程阻塞”按指定时间窗口内每个 Long Task 超过 50ms 的部分求和，**不是 Lighthouse TBT**。rAF 帧间隔是页面回调间隔，**不能直接换算成实体手机屏幕帧率**。LCP 与布局偏移仅描述这 8 秒采样窗口。

三轮优化采样均无页面脚本错误。加载仍存在较长任务，此次减少了首屏布局和非可见动效的成本，不能保证所有设备完全不掉帧。
